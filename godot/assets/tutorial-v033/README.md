# Tutorial atelier paintings

Created for v0.33 with the built-in image generator. All five generated PNG files are included unchanged. Runtime art uses cached AtlasTexture regions from tutorial_atelier_art.gd; regions.json records authoring crops. Rooted gardens use small cached meshes with tip-weighted sway. No runtime texture generation is involved.

There are 12 formation paintings, eight gardens, six plinths, three swim wreaths and four vertical passage paintings. Eight gardens are placed once each; the eleven principal surface barriers use distinct formations; five chest locations use distinct plinths. Small supporting ledges may reuse the formation family. Existing background paintings retain their original motifs.

See generation.json for generator, image hashes, original output names and prompt records. The first four records reconstruct the generation briefs; the passage record retains the exact submitted prompt.
