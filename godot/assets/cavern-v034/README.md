# Friends Cavern production art

Seven original PNG outputs created with the built-in image generator for v0.34. All are copied unchanged. generation.json includes the exact submitted prompts, output names and SHA-256 hashes. prompts.json also records the complete prompt set.

The friends atlas contains Coda, Folio, Luma, Pipette, Tango and Rill. Exact alpha bounds are authored in cavern_friends_data.gd. Cached meshes sample those regions using the existing character-details shader, with individual fin, shell, gill and protected-face zones. The original atlas is not re-encoded or cut into altered image files.

Five new continuous room paintings and one limestone material replace the older generic cavern presentation. The existing Pearl Nursery and Bellflower paintings remain in use. Each room samples one continuous painting from its entrance to its lower pocket; there is no shaft/room artwork join. Some themed paintings are shared across distant chapters with a restrained colour treatment.
