MERMAID ADVENTURE v0.36 — CONNECTED GRACE & THE LIVING ROYAL FAMILY

Windows: extract the Windows ZIP to a new folder and run Mermaid Adventure.exe.
Source: open project.godot using Godot4.4/4.4.1; allow original assets to import.
Android: use official Godot4.5.1 export templates for16KiB-native-page compatibility.
The supplied APK is UNSIGNED and requires the original Mermaid signing key before
installation/update. No replacement key has been invented.

Read CONNECTED-GRACE-036.md for structural changes, exact bone bindings,
rebuild instructions, visual review, performance and remaining limits.
Current evidence: verification/connected36. Stable application/save identity retained.

Swim: arrows / WASD / controller left stick.
Boost: Space / controller B. Jump: J or Shift / controller A.
Bubble: hold B or Z / controller X, then release.
Pause: Escape / P / controller Start.
Options: sound, Gentle Motion and Economy graphics.

The original Whimsy/Friends Cavern adventure, all characters, paintings, royal
models, treasure chests, dialogue, progression and saves remain.
Physical Windows/Android execution and device performance remain untested here.
